# Project context

This is m60motorway.com: a map of Manchester's M60 and its 27 junctions. It is a dependency-free static site. There is no build step for the
page; only the map data is generated.

## What is here

- `src/page.html` is the page template: a full-window map with a floating title, tools and a panel. The panel is the ring as a list: all 27 junctions grouped by stretch, with the chosen one opened in place to show its signs. An ⓘ button swaps the list for About: the illustrated scene of the Barton High Level Bridge, "Good to know" (the road's quirks, with links back to their junctions) and its history.
- `src/styles.css` holds the whole visual system, both themes and the responsive layout.
- `src/script.js` draws the map from `data/geo.js`, and handles pan and zoom, the junction list, About and "Drive the loop".
- `src/render.js` builds the list and "Good to know" HTML. The browser and the build both use it, so the markup stays identical. Change markup there, not in two places.
- `data/junctions.js` holds the words: each junction's place, name, sign destinations for both directions, and note, the stretches that group the list, and the "Good to know" items shown under About.
- `data/geo.js` is generated by `scripts/build_geo.py` from the OpenStreetMap extracts in `scripts/osm/`. Do not edit it by hand.
- `scripts/build_site.mjs` builds `site/` (git-ignored): the home page, a page per junction at `/junction-N/`, a 404 page, `sitemap.xml` and `robots.txt`. Each page has its own title, description, canonical URL and structured data, and the junction list written into the HTML.
- `.github/workflows/pages.yml` builds and deploys `site/` to GitHub Pages on every push to `main`. The custom domain, m60motorway.com, is set in the repository's Pages settings.
- `scripts/build_artifact.py` bundles the built home page into one file for a Claude artifact preview.
- The icons (`src/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`) all draw the same mark as the page title: the ring in dusk rose with a gold dot at J1. Regenerate the PNGs and `.ico` with `python3 scripts/make_icons.py`; new assets in `src/` must be added to the `ASSETS` list in the build.

## Search

The site is built to be found for junction-level searches ("M60 junction 18",
"Simister Island"). Keep the words in the HTML (through `render.js` and the
build) rather than only drawing them with JavaScript, keep list rows as real
links to the junction pages, and add any new page to the sitemap in the build.
On the site, choosing a junction changes the address to that junction's page.

## Design intent

The page is one screen with no page scroll and no header bar: everything floats
over the map, and the panel is one plain list rather than tabs. Keep list rows to
number, place and roads; quirks and trivia belong in a junction's note or under
About, not in the list. On phones the panel is
a bottom sheet that collapses to its top bar. The map is fitted into the space the panel leaves, so the ring is never
hidden behind it. The site is a reference, not a learning tool; don't add quiz
or memorisation features.

The look follows David's personal site, dejones.io: warm paper, green-black ink,
Lora for display and DM Sans for UI, soft shadows, generous space, and a
hand-drawn scene. The M60 itself is drawn in dusk rose; the selected junction and
its next stretch are gold. Avoid road-sign blue and industrial styling.

Keep both themes coherent. The theme is stored in `localStorage` under `theme`
and applied as `data-theme` on `<html>` before first paint. Keep reduced motion
working: the bridge scene's animations pause, and the map's animated zoom is
skipped.

Map symbols (tokens, labels, tags, the car) are drawn at a constant screen size
by scaling them with the map's units-per-pixel on every layout. Tokens are pushed
apart by a small relaxation so none overlap; labels that would collide with a
token, a tag or the road are hidden rather than moved.

## Analytics

Google Analytics (GA4, `G-Y6TC9407P5`) is in the `<head>` of `src/page.html`, so
every built page has it. It loads only when the page is served from
m60motorway.com, so local previews and the artifact never reach the reports.

## Facts

Junction facts come from the Wikipedia junction list (driver location signs) and
OpenStreetMap junction names. Do not invent destinations. If a fact is uncertain,
leave it out.

## Working locally

```sh
node scripts/build_site.mjs && python3 -m http.server 8765 --directory site
```

Before handing off a visual change, check light and dark themes, a phone width
and a desktop width, the browser console, and reduced motion.
